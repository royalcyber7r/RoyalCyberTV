# 📺 **RoyalCyberIPTV**

Android IPTV app with **300+ Live TV channels** using **HLS/M3U8** streaming.

## ✨ Features

* 📺 300+ Live TV Channels
* ▶️ HLS / M3U8
* 🔎 Channel Search
* 📱 Android Support
* 📺 Android TV Support
* 🎬 Fullscreen Player

## 🛠️ Technology

* Kotlin
* AndroidX Media3 / ExoPlayer
* HLS / M3U8
* Gradle
* GitHub Actions

## 🚀 Build APK

1. GitHub → **Actions**
2. **Build APK** → **Run workflow**
3. Build শেষ হলে **Releases** খুলুন
4. `RoyalCyberTV.apk` ডাউনলোড করুন
